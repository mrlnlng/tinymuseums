# Background music

`hall.mp3` is a **clip**, not the full track — currently 150 seconds, ~2.3MB. It is
generated by `scripts/prep_assets.py` and committed, like the other generated assets, so
a fresh clone works without the source pack.

## Regenerating or re-cutting it

```bash
python3 scripts/prep_assets.py apps/web/public/assets

# a different span:
TINY_MUSEUM_AUDIO_START=90 TINY_MUSEUM_AUDIO_SECONDS=180 \
  python3 scripts/prep_assets.py apps/web/public/assets

# or directly:
python3 scripts/clip_audio.py <source.mp3> apps/web/public/audio/hall.mp3 \
  --start 90 --duration 180
```

The source track (~59 minutes, 54MB) lives with the art pack, outside the repo.

## How the clip is made

`clip_audio.py` cuts on MPEG frame boundaries and copies the frames through untouched —
no decode, no re-encode, no quality loss. It also drops any Xing/Info header frame, which
describes the whole file and would otherwise misreport the clip's duration.

**It cannot crossfade.** The clip ends where it ends, so looping has a seam. If the seam
is noticeable, move `--start` until the span begins and ends somewhere quiet. Fixing it
properly needs a real audio tool; there is no ffmpeg on this machine.

## Playback

- `preload="metadata"` — the file is fetched only when playback actually starts, so
  visitors who mute never download it.
- Volume 32% with a fade in and out (`TARGET_VOLUME` in `src/components/SoundProvider.tsx`).
- Starts on the first user gesture; browsers refuse audio before one.
- On by default (`DEFAULT_ENABLED`), remembered per visitor in localStorage.
- In production, serve it from the CDN instead: `NEXT_PUBLIC_MUSIC_URL=https://.../hall.mp3`.
