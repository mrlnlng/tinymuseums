# Assets

Most files here are generated by `scripts/prep_assets.py` from the art pack, which is kept
outside the repo (`TINY_MUSEUM_ASSETS` points the script at it). Do not edit generated files by
hand; regenerate them:

```bash
python3 scripts/prep_assets.py apps/web/public/assets [source-dir]
cp apps/web/public/assets/frame.png apps/web/public/assets/manifest.json packages/core/assets/
```

`packages/core/assets/` holds only the two files the server-side frame renderer reads.

## Monets Lily Pond (2026-11-08)

The four source images in `/home/shan/Downloads/mocks/2026-11-08/fishing scene`
are aligned layers on one canvas. The scene replaces the night garden; the
sparkles are ambient foliage highlights, the splash is an event effect for casts
and bites, and the lily is a floating decoration at its authored position.
The room and fishing view share the same scene, lily, sparkle placement and water
geometry. Both retain the existing fishing rules and woodland landmarks.

Reimport this drop and rebuild its content-hashed 2×/3× WebPs from the repo root:

```bash
node apps/web/tooling/import-fishing-assets.mjs '/home/shan/Downloads/mocks/2026-11-08/fishing scene'
```

The importer updates only these four manifest entries. It retains source resolution
and transparency, records each overlay's original bounds before trimming, and
stores the new shoreline in `pond/layout.json` so shadows and walking follow the art.

## Fishing forest illustrations

`pond/forest-door.png`, `forest-noticeboard.png`, `forest-fisherman.png` and
`forest-journal.png` are new reference-guided illustrations made with the built-in
image generation tool. They use the original fashion doorway, pond and character
art as style references. The original files were retained unchanged. Matching
`.webp` files are alpha-preserving runtime exports.

Prompts, references and sequential in-game review notes are in
[`docs/pond-asset-art-direction.md`](../../../../docs/pond-asset-art-direction.md).

The fishing forest now uses the original animated otter as its shopkeeper, with
`pond/fishing-apron.webp` attached to its chest. `pond/forest-bait-shop.webp`
replaces the generated fisherman/basket in the scene, and
`pond/forest-noticeboard-wood.webp` supplies the board's wooden header. Source
PNGs and the exact built-in image_gen prompts are recorded in the
[art direction notes](../../../../docs/pond-asset-art-direction.md#5-current-revision-original-otter-bait-stall-and-quiet-exploration).
