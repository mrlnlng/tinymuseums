# Assets

Most files here are generated by `scripts/prep_assets.py` from the art pack, which is kept
outside the repo (`TINY_MUSEUM_ASSETS` points the script at it). Do not edit generated files by
hand; regenerate them:

```bash
python3 scripts/prep_assets.py apps/web/public/assets [source-dir]
cp apps/web/public/assets/frame.png apps/web/public/assets/manifest.json packages/core/assets/
```

`packages/core/assets/` holds only the two files the server-side frame renderer reads.
